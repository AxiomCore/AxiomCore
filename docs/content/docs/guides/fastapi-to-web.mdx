Keep FastAPI as the executable backend and ordinary web code as the frontend.
AxiomCore supplies the contract between them. This guide runs a real Python
service and browser request; it does not use mock responses.

## Prerequisites

Use [CLI 0.149.0](/getting-started/installation), Python 3.12, Node.js 22.12+
(or a compatible supported Node release), npm, and two terminals. Download the
[complete FastAPI/web source](/examples/fastapi-web.zip).

```bash title="Terminal 1: example root"
unzip fastapi-web.zip
cd fastapi-web
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
axiom install axiom-fastapi --module
```

FastAPI extraction imports your application. Keep imports free of migrations,
worker startup, production connections, and destructive setup. The example
initializes only models, routes, and local CORS configuration.

## Create and review the contract source

The example already contains its Acore source and backend manifest. For your
own app without an existing Acore file, run
`axiom init main.py:app --module axiom-fastapi` from its backend directory.
Replace `main.py:app` with the actual entrypoint.

```bash title="Terminal 1"
cd backend
axiom eval axiom.acore
axiom build axiom.acore --out backend.axiom
axiom inspect backend.axiom
```

Review method/path, required inputs, response models, validation, authentication,
and errors. Extraction cannot infer every business rule in a handler. The
example's `GET /greet/{name}` returns `{"message":"Hello, Ada!"}` for Ada;
FastAPI rejects names longer than 40 characters with 422.

## Run the real backend

```bash title="Terminal 1: backend"
../.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8083
```

The API remains Python. Extraction and contract construction do not deploy it
or enforce a contract around every handler. Use an explicit
[server adapter](/backend/adapters) when you need that boundary.

## Pull the web client

Open a second terminal in the example root:

```bash title="Terminal 2"
cd frontend
npm ci
axiom pull ../backend/backend.axiom --framework atmx-web --name greetings --out generated
npm run dev
```

The project pins **atmx-cli 0.146.7** before `pull`. CLI 0.149.0's automatic
companion package is not currently published, so an unprepared project can fail
with npm `ETARGET`. The pinned local generator above was verified with this
contract and **atmx-web 0.147.5**. Pin and test your own contract's combination.

Open `http://127.0.0.1:5175` and select **Say hello**. The page shows
**Hello, Ada!** from the running service. The generated contract asset and
self-hosted Wasm asset are served from the frontend origin.

## Initialize before querying

The complete `frontend/main.ts` configures the generated contract for port
8083 and awaits `atmx.init`. It checks `ready.ok` before enabling calls.
An imperative query returns a subscription handle:

```ts title="frontend/main.ts: query excerpt"
const query = atmx.query('greetings.greet', { name: 'Ada' });
const unsubscribe = query.subscribe((state) => {
  if (state.error) output.textContent = state.error.message;
  else if (state.data) output.textContent = state.data.message;
});
// On replacement or page disposal:
unsubscribe();
query.dispose();
```

Use your generated operation names and types. Do not treat the query handle as
an awaited data value. The [web integration reference](/frontend/web) covers
cache and authentication APIs.

## Exercise a local boundary

Use [contract tests](/testing/contracts) and [explicit mocks](/testing/mocks)
for declared behavior during frontend development. Those checks complement
the real request above. A mock does not prove the FastAPI handler's behavior.

## Validate the application

- Verify a successful request and the overlong-name error, including direct API calls.
- Check missing/invalid input and browser-visible errors.
- Verify base URL, CORS allowlist, credentials where used, loading/empty states, and cache privacy.
- Test a fresh browser session; stored cache must not hide startup failures.
- Retain source, contract, dependency lock, test output, and the semantic diff for release review.

This fixture is a public, stateless greeting API. Add your application's
identity and data policies separately. Stop both servers with Ctrl-C. Remove
the disposable directory if you no longer need its venv and generated files.
