Capability support is specific to a framework, database, target, and tool
version. The general feature matrix was last reviewed against the repositories on
**September 22, 2026**.

The distribution and new local app walkthroughs were checked on **October 15,
2026** with published CLI 0.149.0 and signed web host 0.6.12 on macOS arm64.
Detailed database and advanced-language qualifications retain their own review
baselines in the [capability reference](/reference/capability-boundaries).

## Status definitions

| Status | Meaning |
| --- | --- |
| **Available** | Usable on the stated path. This does not imply a stable major release or universal production certification. |
| **Alpha** | Implemented and testable; APIs or workflows may change. |
| **Experimental** | A bounded implementation exists; compatibility, parity, or distribution is incomplete. |
| **Coming soon** | No supported runnable workflow is available. |

## Language, contracts, and packages

| Capability | Status | Scope |
| --- | --- | --- |
| Acore language, `.axiom` contracts, typed packages, resolution and semantic diff | Alpha | Use compatible tools and pinned locks |
| Managed logic, concurrency, caching, streams, scenarios, and typed failures | Experimental | Requirements vary by feature and host; see [exact boundaries](/reference/capability-boundaries#language-contracts-and-packages) |
| Executable extensions | Experimental | Selected Rust, TypeScript, and Python profiles; no arbitrary ecosystem compatibility |
| Inspector | Alpha | Canonical facts, relationships, impact and recorded execution evidence |
| Optional Jev question planning | Experimental | Remote intent planning; local evidence remains authoritative |

## Backend and schema inputs

| Path | Status | Main boundary |
| --- | --- | --- |
| FastAPI extraction | Available | Imports the application; install its dependencies and keep initialization safe |
| Go extraction | Alpha | Check the selected router and extracted types |
| OpenAPI and SQL bootstrap | Experimental | Bounded imports, not full behavior or runtime parity |
| PostgreSQL and SQLite contracts/persistence | Experimental | [Engine, platform, and workflow limits](/reference/capability-boundaries#backend-and-schema-inputs) |
| Named PostgreSQL production profile | Available | Only its exact qualified release, recovery admission, and measured workload |
| Other first-party backend extractors | Coming soon | No supported extractor workflow is documented |

## Frontend and application targets

| Path | Status | Main boundary |
| --- | --- | --- |
| Vanilla web / ATMX | Available | Verify browser startup, runtime, CORS and application behavior |
| React / ATMX | Alpha | Verify bundler, provider, and application lifecycle |
| Flutter / Dart | Alpha | Verify assets, native runtime, storage and release builds |
| Swift / Apple | Experimental | Distribution foundations; full binding/lifecycle parity is incomplete |
| Acore UI | Alpha | Browser and qualified emulator/simulator development paths |
| Extension hosts and foreign web islands | Experimental | [Target-specific limits](/reference/capability-boundaries#frontend-and-application-targets) |
| Physical devices and app-store distribution | Coming soon | No general certification claim |

## Cloud and applications

Connected accounts, projects, releases, environments, tests, observability, and
the Cloud Dashboard are **Alpha** and require their configured services.
Axiom Studio, Acode, and Axiom Marketplace are **Coming soon**.

## Database DX delivery

CLI 0.149.0 provides versioned run, migrate, rollback, status, history,
comparison, and typed application storage. PostgreSQL needs a reachable server
and a matching validator. SQLite uses a local file. Browser previews simulate
storage and history; they do not perform native migrations.

The current 0.149.0 release has a macOS arm64 binary. It does not include Linux
or native Windows downloads. Installer platform detection does not establish
artifact availability. See [installation](/getting-started/installation) and
[the detailed reference](/reference/capability-boundaries#database-developer-workflow)
for constraints outside the checked local path.
