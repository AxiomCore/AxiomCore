**AxiomCore connects the parts of an application through typed, versioned
contracts.** Keep a supported backend and frontend, or use **Acore** to author
your API, UI, and database schema.

A contract describes the operations, data, validation, and behavior a consumer
can rely on. Build it, review changes, and use it from a compatible client.
