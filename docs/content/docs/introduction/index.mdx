# AxiomCore

AxiomCore is a **deterministic behavioral layer** that completely eliminates manual API integration. Instead of writing fragile network requests, caching logic, and error handlers in your frontend, AxiomCore embeds a high-performance **Generic Runtime** (powered by Rust and WebAssembly) directly into your app.

You write your backend in **FastAPI** or **Go**. Axiom extracts it, wraps it in a behavioral contract (`.acore`), and executes it identically across Flutter, React, iOS, and Vanilla Web.

### The Axiom Workflow

AxiomCore replaces OpenAPI (Swagger) and GraphQL with a cryptographically signed binary artifact (`.axiom`). This artifact dictates exactly *how* the API behaves, not just what the data looks like.

## 🚀 Ecosystem Status

AxiomCore is currently in **Private Alpha**. We provide first-class support for the following stacks:

| Layer | Supported Tech | Status |
| :--- | :--- | :--- |
| **Backend Extractors** | Python (FastAPI), Go (Native) | Alpha |
| **Contract Language** | Acore (PKL-based) | Alpha |
| **Mobile / Desktop** | Flutter, Swift (SPM), macOS, iOS | Alpha |
| **Web (ATMX)** | React, Vanilla HTML/JS, Alpine.js | Alpha |

### What's New?
*   **ATMX Web Engine:** Instant DOM hydration before Wasm even boots using `sessionStorage` caching.
*   **Axiom Marketplace:** Pull third-party API contracts (Stripe, Twilio) directly into your app without reading their docs.
*   **JSON-Atom Diffing:** Mathematical changelogs and terminal GUI diffs for API updates.
