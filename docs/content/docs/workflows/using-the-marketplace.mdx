title: Axiom Marketplace
description: Planned discovery and installation for reusable Axiom packages.
---

<StatusNote status="coming-soon" title="No supported marketplace workflow yet">
  Axiom Marketplace is a product direction. There is currently no public
  catalog or supported command for browsing and installing marketplace
  packages. Examples on this page are conceptual, not runnable instructions.
</StatusNote>

The planned Marketplace will provide one discovery surface for independently
versioned Axiom packages, including:

- service/API contracts;
- themes and component libraries;
- database-schema packages;
- extension metadata and capability requirements; and
- application-policy packages.

The package foundation already exists: `.axiom` envelopes carry a kind,
identity, version, targets, canonical payload, and integrity data, and local
resolution can produce a committed dependency lock. Marketplace work will add
catalog, publisher, trust, review, and supported installation experiences on
top of that foundation.

Until then, use only the local or connected package-resolution workflows that
are explicitly documented elsewhere. Do not depend on a provider package by
name unless you control and verify its artifact and lock.
