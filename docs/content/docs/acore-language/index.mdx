**Acore is the declarative language used to author AxiomCore applications and
contracts.** Learn expressions and types, then choose an application profile.
Acore is an independent language and does not require a Pkl runtime.

<StatusNote status="alpha" title="Version your source and dependencies">
  Pin compatible tools and packages, and review semantic changes when upgrading.
  Core language, backend, frontend, and database capabilities have separate
  support boundaries.
</StatusNote>

## Contract profiles

`AxiomDeps.toml` selects the project profile. A declaration accepted by one
profile is not automatically valid in another.

| Profile | What you author | Continue with |
| --- | --- | --- |
| Backend | Models, endpoints, actions, validation, policies | [Backend declarations](/acore-language/backend-profile) |
| Frontend | Apps, pages, forms, state, queries, mutations, views | [Acore UI](/frontend/acore-ui) |
| Database | Tables, keys, relationships, constraints, schema versions | [Database contracts](/database/contracts) |
| Package | Theme, component-library, database-schema, extension, application-policy exports | [Package lifecycle](/workflows/package-lifecycle) |

Backend and package builds produce `.axiom` artifacts. Acore UI runs locally or
builds a `.axiomapp` application package.

## Minimal service source

For an existing FastAPI app, extraction begins with an explicit source:

```acore title="backend/axiom.acore"
amends "axiom-fastapi:./main.py:app"
project(id: "tasks-api", version: "0.1.0")
policies(retry: RetryPolicy(maxAttempts: 3))
```

Install the extractor and Python dependencies first. Follow the
[FastAPI guide](/guides/fastapi-to-web) to run the complete integration.

## Minimal Acore UI source

```acore title="frontend/main.acore"
module example.hello.ui
app Hello { route "/" => Home }
page Home {
  view {
    SafeArea { Text("Hello from Acore") }
  }
}
```

The [frontend quickstart](/getting-started/quickstart-frontend) includes the
manifest and run command. The [base schema reference](/reference/acore-schema-reference)
provides exact fields and defaults.
