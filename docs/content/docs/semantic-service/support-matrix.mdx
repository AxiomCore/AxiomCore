This page lists what the preview `acore-semantic` serves. Ask a running
service with the `capabilities` operation; its manifest is the authority, and
the tables below are generated from the same manifest and the service's
support record. A table entry never claims more than the manifest.

<StatusNote status="experimental" title="Preview">
  The whole service is a preview on macOS arm64. The statuses below describe
  the service's own scope, not production readiness.
</StatusNote>

## Status definitions

| Status | Meaning |
| --- | --- |
| `implemented` | Served, with passing tests for every declared behavior. |
| `partial` | Served, but some declared behavior is missing. The Missing column lists exactly what. |
| `planned` | Not served. A request answers `unsupported_operation` (`not_implemented`). No entry is planned in this build. |

## Summary

{/* BEGIN GENERATED summary */}

- Protocol: `axiom-agent-semantic/v1`. Service version: `0.1.4`.
- Profiles: `acore-ui` (partial; targets `web`).
- Operations: 5 implemented, 12 partial. Edit families: 7 implemented. Checks: 2 implemented.
- Publication: `local_filesystem`, partial. Not provided: atomicity across files for other readers; power-loss and OS-crash durability; remote publication.

{/* END GENERATED summary */}

The service works on one root per workspace, the local filesystem, profile
`acore-ui` and target `web`. It was tested on four Acore UI projects, from the
one-page example to applications with several pages and components. On
November 11, 2026, Claude Code and Codex each completed 16 of 17 edit tasks on
three real projects through the MCP server; neither miss was a wrong or broken
edit by the service.

## Edit families

An edit family is a kind of operation in `change.propose` and `edit.plan`.
`replace_region` is a fallback offered only on a snapshot with syntax errors.

{/* BEGIN GENERATED edit-kinds */}

| Name | Status | Limits | Missing (partial only) |
| --- | --- | --- | --- |
| `set_property` | implemented | Authored literal scalars (String, Int, Float, Bool) on element nodes only. |  |
| `bind_property` | implemented | Binds an element property to a state of its owner; shadowed or duplicate owners are ambiguous_owner. |  |
| `list_element` | implemented | Remove or insert one child of an element or conditional; long nodes are not offered. |  |
| `declaration` | implemented | Create, update and remove of state and action declarations in pages and components; bodies bounded (20,000 characters); removal of a referenced declaration is still_referenced. |  |
| `set_reference` | implemented | On_* handlers to an action of the element's owner with the same parameter types. |  |
| `import` | implemented | Add and remove component and model use lines on a file's first page or component. |  |
| `replace_region` | implemented | Fallback capability: offered only on syntax snapshots, the smallest whole-line region around a syntax error (at most 200 lines and 16 KiB), alone in its batch, judged by the repair rule. |  |

{/* END GENERATED edit-kinds */}

## Publication

`change.apply` publishes to the local filesystem only. Its guarantees, as the
manifest lists them (see [Apply, receipts and recovery](/semantic-service/protocol#apply-receipts-and-recovery)):

{/* BEGIN GENERATED publication */}

- `content_preconditions_before_any_write`
- `precondition_failure_before_first_write_writes_nothing`
- `later_failures_restore_earlier_files_when_possible`
- `per_file_atomic_replace`
- `only_candidate_files_replaced_in_project_sources`
- `idempotent_by_request_id`
- `receipt_with_before_and_after_digests`
- `journal_and_backups_written_before_first_write`
- `interrupted_apply_reconciled_before_next_apply`
- `outcome_unknown_only_while_a_journal_is_unreconciled`
- `no_torn_file_after_a_process_kill`
- `killed_apply_ends_applied_rolled_back_or_needs_attention`
- `external_edit_kept_unless_made_between_recheck_and_rename`
- `reconcile_removes_temp_backup_and_journal_leftovers`

{/* END GENERATED publication */}

## External writes

The service detects files changed by other programs by comparing each
snapshot's inputs with the disk before it answers (file metadata first, then
the SHA-256 of each file whose metadata changed; the hash decides). It does not
isolate you from other writers, and a write after the last check is not
detected. Guarantees:

{/* BEGIN GENERATED external-writes */}

- `reads_revalidated_against_disk_before_answering`
- `changed_snapshot_marked_never_presented_as_current`
- `latest_read_retried_when_inputs_change_during_the_read`
- `content_hash_decides_stat_only_selects`
- `apply_refuses_deleted_or_renamed_base_inputs`
- `apply_reports_other_changed_base_inputs`
- `service_published_changes_reported_as_concurrent_candidate`
- `watcher_failure_never_changes_an_answer`

{/* END GENERATED external-writes */}

## Not supported

{/* BEGIN GENERATED unsupported */}

- Multi-root (multi-project) workspaces.
- Profiles other than acore-ui and targets other than web (reported as unsupported_profile).
- Context.build purpose change_schema (backend profile).
- Observed-layer facts, test associations and authorization policies.
- Expression- or statement-level bounded-body edits; cross-module signature edits; rename, move and extract refactors.
- Concurrent candidate rebase and read-set preconditions.
- Backend, data, schema and API edit families.

{/* END GENERATED unsupported */}

Other limits of this build:

- One service process serves one project root. There is no isolation between
  callers inside one process.
- Secrets written in `.acore` source are source text and are returned by
  reads. The service has no secret store.
- Only `project.overview` has a continuation cursor. Other truncated answers
  report what they omitted; narrow the request instead.

## Regenerate this page

From the `docs` directory, with the protocol definition and a service binary:

```bash title="docs directory"
node scripts/generate-semantic-service.mjs --protocol <protocol-dir> --binary <acore-semantic>
```

The script fails if the support record and the binary's manifest disagree on
any status, guarantee, operation or error code. Add `--check` to verify the
generated tables without writing them.
