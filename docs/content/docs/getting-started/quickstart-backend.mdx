Run a small API authored in Acore. If you already have a service, follow the
[FastAPI integration](/guides/fastapi-to-web) or [Go integration](/guides/go-to-web)
instead. Those paths retain your existing backend.

<span id="diagnose-and-plan" />

## Prerequisites

[Install CLI 0.149.0](/getting-started/installation). Create an empty `hello-api`
directory and run the commands below from that directory. This example uses
port 8081 and has no external providers or database.

## 1. Define the project and endpoint

```toml title="AxiomDeps.toml"
type = "backend"
targets = ["server"]
audiences = ["web"]
```

```acore title="main.acore"
project(id: "docs.hello", version: "1.0.0")
variant default(include: ["*"])
model Greeting { message: String }
action hello(kind: ActionKind.query, output: Models.Greeting) {
  managed { return {message: "Hello from Acore"} }
}
endpoint hello(method: GET, path: "/hello") {
  handle(action: Actions.hello) // [!code highlight]
  response(type: Models.Greeting)
}
```

The action returns a typed value. `handle` connects the public endpoint to
that action. Request validation and response types belong to the contract.

<span id="build-and-inspect" />

## 2. Build and inspect

```bash title="Terminal 1: hello-api"
axiom check main.acore
axiom build main.acore --out backend.axiom
axiom inspect backend.axiom
axiom server deployment backend.axiom backend.server.json --output deployment.json
```

`--out` exports the contract to a known path. The companion server plan and
deployment configuration stay on the backend; clients receive the public
contract. The deployment scaffold has no provider grants. This action needs
none. Review providers, authentication, and grants before adding real effects.

<span id="exercise-the-development-boundary" />

## 3. Run and verify

```bash title="Terminal 1: hello-api"
axiom run main.acore --deployment deployment.json --port 8081
```

```bash title="Terminal 2"
curl -fsS http://127.0.0.1:8081/hello
```

```json title="Expected response"
{"message":"Hello from Acore"}
```

This is the real action, not a mock. The example's endpoint is public and
returns a constant. Add authentication before exposing protected data.
Stop the process with Ctrl-C when finished.
