---
title: Environment secret metadata
description: List hosted secret definitions and bindings for a configuration environment with the Axiom CLI.
pageType: reference
---

Available in source builds containing these commands. Sign in with `axiom login`
and select a project and configuration environment you can access.

```sh title="Read environment secret metadata"
axiom secrets environment list --project demo --environment development
axiom secrets environment bindings --project demo --environment development --json
```

Both commands require `--project` and `--environment`. Each accepts an ID, slug,
or display name. Ambiguous display names fail; use an ID to select one entry.
`--json` prints the API response without a heading, suitable for scripts.
Without it, output includes a plain-language heading and the metadata fields.
An empty list means there are no entries visible in that environment.

`list` reads the environment's secret metadata. `bindings` reads its secret
bindings. Neither command resolves or prints secret material. These are reads:
no confirmation or step-up sign-in is required. Access restrictions still apply.

To check the selection, compare the returned IDs and binding references with
those in the project's Secrets dashboard for the same environment. Unknown
projects or environments fail before the metadata read. Authentication and API
errors produce a nonzero exit status.

Continue with [secret management](/tooling/secrets-cli) to define secrets or update
bindings.
