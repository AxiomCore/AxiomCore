---
title: Acore Schema Reference
description: The complete API surface of the Acore Standard Library.
---

When writing `.acore` files, you interact with the global `Config` class. Below are the primary objects available in the `acore.base` standard library.

| Class | Properties | Description |
| :--- | :--- | :--- |
| **`Config`** | `project`, `backend`, `frontend`, `variants`, `policies`, `models`, `endpoints` | The top-level root configuration object. |
| **`BackendConfig`** | `language` (String), `entrypoint` (String), `codec` (CodecType) | Defines introspection targets and codec formats (`json`, `flatbuffers`). |
| **`CachePolicy`** | `strategy` (CacheStrategy), `ttlSeconds` (Int) | Local DB caching behavior. Strategies: `network_only`, `cache_first`, `network_first`, `stale_while_revalidate`. |
| **`RetryPolicy`** | `maxAttempts` (Int), `backoff` (Backoff), `retryOnCodes` (List), `retryOnTimeout` (Bool) | Fault tolerance configuration. |
| **`WebSocketDef`** | `direction` (WebSocketDirection), `client` (WsMessageDef), `server` (WsMessageDef) | Configures a persistent Ws/Wss connection. |
| **`EndpointAuth`** | `required` (Bool), `condition` (AuthCondition), `methods` (List) | Associates authentication strategies (`bearer`, `oauth2`) with specific routes. |
| **`NetworkFault`** | `type` (String), `probability` (Float), `delayMs` (Int) | Used in Mocking to inject chaos (`timeout`, `connection_reset`, `slow_response`). |
