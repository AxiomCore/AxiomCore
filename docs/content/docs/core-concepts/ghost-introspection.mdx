Historically, extracting an API schema meant running the backend server. This forced CI/CD pipelines to install massive dependencies (like Pandas or PostgreSQL drivers) just to generate a Swagger file.

AxiomCore solves this using **Ghost Introspection**.

### Decoupled Extractors
Axiom CLI uses specialized binaries that parse Abstract Syntax Trees directly from your source files. You can install extractors on demand:

```bash
axiom install axiom-fastapi --module
axiom install axiom-go-extractor --module
```

### The "Amends" Bridge
In your `.acore` file, the `amends` keyword triggers the Ghost Extractor:

```pkl
// Introspect a Python FastAPI application
amends "axiom-fastapi:./src/main.py:app"

// Introspect a Go Gin/Chi router
amends "axiom-go:./cmd/server/main.go"

// Or pull a standard OpenAPI spec from a URL!
amends "axiom-openapi:https://api.stripe.com/v1/spec.yaml"
```

<Callout type="info">
**Zero Environment Setup:** You can run `axiom build` on a bare-bones Ubuntu CI runner or an M3 Mac. Because the extractors don't execute the backend logic, they don't care if your database is offline or if your ENV variables are missing.
</Callout>
