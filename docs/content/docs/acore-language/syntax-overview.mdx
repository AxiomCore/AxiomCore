---
title: Syntax Overview
description: Understanding the object-oriented configuration engine.
---

Acore is a statically-typed configuration language built on top of Apple's PKL. It allows you to declare JSON-like structures but with inheritance, functions, and strong validation.

### Object Definitions

```pkl
class ProjectConfig {
  id: String
  version: String
}

project = new ProjectConfig {
  id = "my-service"
  version = "1.0.0"
}
```

### Modifiers

Acore supports modifiers to control visibility and immutability:
*   `local`: Variable is available in scope but won't be exported to the `.axiom` binary.
*   `hidden`: Property is invisible to final serialization (useful for helper objects).
*   `open` / `abstract`: Allow a class to be extended by other classes.

```pkl
hidden helperValue = 42
local tempString = "Do not export me"
```

### Control Flow

Acore supports late-binding and conditionals:

```pkl
isProduction = read_env("ENV") == "prod"

cacheTTL = if (isProduction) 3600 else 60
```
