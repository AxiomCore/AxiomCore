The AxiomCore name covers a language, local toolchain, runtime ecosystem, and
cloud services. The larger product direction also includes visual and
collaborative applications that are not yet available.

## Product direction

<StatusNote status="coming-soon" title="Axiom Studio">
  A planned visual workspace for building software on AxiomCore: visual frontend
  composition, backend/API management, database views, task and Kanban views,
  human/agent collaboration, chat, and a contract-aware audit journey. There is
  no installable Studio application today.
</StatusNote>

<StatusNote status="coming-soon" title="Acode">
  A planned contract-aware code editor for source, semantic contract diffs, and
  ordinary imperative modules. Acore has editor and language-server foundations,
  including an existing editor extension, but those are not the Acode IDE.
</StatusNote>

<StatusNote status="coming-soon" title="Axiom Marketplace">
  A planned unified catalog for contracts such as UI components, themes,
  service/API integrations, database schemas, extensions, and policies. The
  typed package envelope exists, but there is no supported marketplace browsing
  or installation workflow today.
</StatusNote>
