Support is specific to a framework, database, target, platform and tool
version. Find your path below before you rely on it. The general feature matrix
was last reviewed against the repositories on
**September 22, 2026**.

Other review dates:

- **Distribution and platforms** were checked on October 21, 2026 against the
  published release assets.
- **Run your first app** was run end to end on October 21, 2026 with published
  CLI 0.149.1 and signed web UI host 0.6.12 on macOS arm64.
- The backend, frontend and database quickstarts were checked on October 15,
  2026 with published CLI 0.149.0 and web UI host 0.6.12 on macOS arm64.
- Detailed database and advanced-language qualifications keep their own
  baselines in [Capability boundaries](/reference/capability-boundaries).

## Status definitions

| Status | Meaning |
| --- | --- |
| **Available** | Usable on the stated path. This does not imply a stable major release or universal production certification. |
| **Alpha** | Implemented and testable; APIs or workflows may change. |
| **Experimental** | A bounded implementation exists; compatibility, parity or distribution is incomplete. |
| **Coming soon** | No supported runnable workflow is available. |

## Distribution and platforms

The Axiom CLI release is **0.149.1** (October 15, 2026).

| Platform | Status | CLI 0.149.1 | Boundary |
| --- | --- | --- | --- |
| macOS arm64 (Apple silicon) | Alpha | Archive published | Installer script, Homebrew or manual download. All walkthroughs are checked here. |
| Linux amd64 | Experimental | Archive published | Installer script only. Needs glibc 2.36 or newer (for example Debian 12 or Ubuntu 24.04). Includes a managed PostgreSQL 17 validator. Walkthroughs, extractors and UI hosts are not checked on Linux. |
| Linux arm64 | Experimental | Archive published | Same as Linux amd64. |
| macOS on Intel (x86_64) | No build | None | The installer detects the platform but finds no archive. |
| Windows | No build | None | No native build; the installer rejects Windows. WSL2 is not checked. |
| Alpine and other musl Linux | No build | None | The installer requires glibc. |

Installer platform detection does not establish artifact availability. Other
published tools have narrower platforms:

| Tool | Version | Published platforms |
| --- | --- | --- |
| Web UI host | 0.6.12 (signed) | Web browser host; Android Emulator and iOS Simulator hosts |
| FastAPI extractor | 0.1.4 | macOS arm64 |
| Go extractor | 2026.10.14.2 | macOS arm64 |
| Acore language server (`acore-lsp`) | 0.1.4 | Bundled in the CLI; standalone build for macOS arm64 |

See [Install the Axiom CLI](/getting-started/installation) for commands and
checksums.

## Cloud and applications

Connected accounts, projects, releases, environments, tests, observability and
the Cloud Dashboard are **Alpha** and need their configured services. Axiom
Studio, Acode and Axiom Marketplace are **Coming soon**.

Project environment secret management is **Alpha** in the deployed Dashboard.
Protected local and Cloud consumption is **Experimental** in the matching
source preview on macOS arm64 with native ActionHost and server WASM. The
source web frontend uses delegated backend operations. Native mobile runtime
parity and container or Worker consumption are unqualified. Published CLI
0.149.0 and 0.149.1 and host 0.6.12 do not include this qualification. See
[Secrets at runtime](/backend/runtime-secrets).

[Cloud secrets](/cloud/secrets) describes the deployed inventory, candidate
review, runtime access and activity workflow, and secret environment
protection and expiry. The [Secrets commands](/tooling/secrets-cli) reference
covers the explicitly qualified source-preview commands.

## Local database workflow

CLI 0.149.0 and later, including 0.149.1, provide versioned run, migrate,
rollback, status, history, comparison and typed application storage.
PostgreSQL needs a reachable server and a matching validator; the Linux CLI
archives include a PostgreSQL 17 validator. SQLite uses a local file. Browser
previews simulate storage and history; they do not perform native migrations.
See [Capability boundaries](/reference/capability-boundaries) for constraints
outside the checked local path.

## Managed project databases

Dashboard database preferences, managed storage provisioning and resource
lifecycle controls, including qualified access rotation, are **Alpha**, checked
on October 20, 2026. Customers select SQLite or PostgreSQL; allocation depends
on location, capacity and entitlement. Hosted runtime connections, migrations,
managed application authentication and public paid checkout are
**Coming soon**. New resource-management CLI commands are source-only. See
[Managed resources](/cloud/project-resources) and the local
[database workflow](/database).
