The Axiom Flutter SDK wraps the native Rust runtime via **FFI**. It provides a reactive, stream-based UI architecture with zero network boilerplate.

### 1. Initialization
You must boot the runtime once in `main()`. Provide a path for the **Sled** database to enable local caching.

```dart
import 'package:axiom_flutter/axiom_flutter.dart';
import 'package:path_provider/path_provider.dart';
import 'package:my_app/axiom_generated/axiom_sdk.dart';

late final AxiomSdk sdk;

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final dir = await getApplicationDocumentsDirectory();

  // The config is auto-generated by `axiom pull`
  sdk = await AxiomSdk.create(
    config: AxiomDefaultConfig.config, 
  );

  runApp(MyApp());
}
```

### 2. Reactive UI with AxiomBuilder
Do not use `FutureBuilder`. Use `AxiomBuilder` to bind directly to the Rust engine's event stream (`Loading -> CacheHit -> NetworkSuccess`).

```dart
AxiomBuilder(
  query: sdk.users.getUser(id: 1),
  loading: (context) => const CircularProgressIndicator(),
  error: (context, error) => Text("Failed: ${error.message}"),
  builder: (context, state, user) {
    return Column(
      children: [
        Text(user.name),
        if (state.isFetching) const Text("Refreshing in background..."),
      ],
    );
  }
)
```

### 3. Forms with AxiomMutationBuilder
Mutations (POST/PUT/DELETE) bypass the cache entirely. The `AxiomMutationBuilder` provides an `execute` function to trigger the Wasm/Rust engine.

```dart
AxiomMutationBuilder(
  mutation: sdk.users.updateUser,
  builder: (context, state, execute) {
    return ElevatedButton(
      onPressed: state.isMutating ? null : () {
        execute({"name": "New Name"});
      },
      child: state.isMutating ? const CircularProgressIndicator() : const Text("Save"),
    );
  }
)
```

<Callout type="info" title="Field-Level Error Handling">
Rust validation errors (via `rod-rs`) are exposed cleanly in Dart. You can extract specific field errors directly from the state: `state.error?.getFieldError('email')`.
</Callout>
