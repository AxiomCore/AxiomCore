These guides connect the individual language and CLI references into complete,
reviewable outcomes. They deliberately preserve the application framework you
already use and introduce AxiomCore at one contract boundary at a time.

<StatusNote status="alpha" title="Validate your exact stack">
  These paths use implemented commands, but AxiomCore is still alpha. Pin the
  CLI and extractor versions used in CI, retain the generated lock and artifact,
  and run a consumer test before promoting a release.
</StatusNote>
