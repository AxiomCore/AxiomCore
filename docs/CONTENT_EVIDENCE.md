## Claim-change procedure

1. Update or add an evidence row in the same change as the public claim.
2. Link to the narrowest implementation and name the validation boundary.
3. Run the owning repository's tests plus the docs type/build checks.
4. Record a new review date only after the whole ledger has been rechecked.
